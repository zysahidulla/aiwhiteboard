AI Virtual Whiteboard

A hand-tracking drawing app built with Python, OpenCV, Pillow, and MediaPipe. It uses your webcam to detect hand gestures and lets you draw on a virtual canvas.

View GitHub Repo Read the README
GitHub Pages is a static hosting service, so this page is a landing page for the project. The actual webcam app runs locally on your machine using Python and camera access.

What it does

  • Draw with your index finger
  • Erase using an eraser gesture
  • Undo and clear the canvas
  • Change colors using the gesture palette
  • Save your created drawing as an image
